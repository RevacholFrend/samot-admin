SAMOT Packager

Собирает папку игры в релиз для GitHub Releases: паки с SHA-256 + манифест + инструкция.

1

Папка с готовой игрой

Внутри должны быть финальные файлы игры — без исходников, .git, node_modules.

2

Точка входа (.exe, для кнопки «Играть»)

Определяется автоматически: единственный .exe выбирается сам, иначе — самый большой.

3

Версия и тег релиза

Тег уйдёт в манифест (manifest.tag) и в инструкцию по публикации.

4

Папка результата

Содержимое папки (pack-*.zip + manifest.json) просто прикрепляется к релизу.
